# Anatomy depth-expansion source boundaries

- The scoped upper-limb material contains seven line-addressable video transcripts, but no lower-limb lecture deck or transcript. Lower-limb additions are therefore tagged `book-extension`, not course scope.
- The respiratory lecture folder contains nasal, laryngeal, tracheal, lung and pleural material. It contains no pharynx lecture. New pharyngeal material, where retained, is tagged `book-extension`.
- Several cardiovascular and respiratory decks are image-heavy and yield few searchable words. A slide number is used only when the visible deck topic or the existing verified catalog supports it; otherwise the question is grounded to a printed textbook page.
- Existing repeated 2D and 3D identification variants were excluded from the conceptual-depth count. Existing label-rich atlas images were not attached to new relationship questions because the unmasked labels would disclose answers.
- The supplied sources do not establish a final examination blueprint or prove exhaustive textbook coverage. Coverage records preserve unfilled and unknown boundaries.

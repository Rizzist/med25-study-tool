# Cardiovascular anatomy — curated 3D trainer scope

High-yield gross-anatomy scope for a med-school 3D study trainer, aligned to the regional coverage expected from *Gray's Anatomy for Students* and Snell. The model should use anatomical position (`+Y` superior, `+Z` anterior, `+X` subject-left) and the engine tissue union specified in `docs/anatomy3d/SPEC.md`.

**Scope rule:** paired structures are one quiz target when learners normally identify them as a set (for example, papillary muscles or pulmonary veins); right/left structures remain separate where their course or relationships are independently examinable. Every `distractorIds` value resolves to another ID in this document.

**Organ-tissue flag:** a new `organ` tissue is **not warranted for this scope**. The selectable anatomy can be represented by `muscle`, `cavity`, `membrane`, `ligament`, `artery`, and `vein`. If a future manifest makes the whole heart a separate selectable structure rather than a scene container, `organ` should then be considered.

**FMA policy:** `?` means that an exact BodyParts3D/FMA node has not been verified; do not substitute a parent-organ FMA ID for a more specific structure.
